# VaneQuiros — Página Web

Portal multipágina para el ecosistema de marcas de Vanessa Quirós.

## Estructura

- `index.html` — Portal unificador (3 marcas)
- `vanessa-quiros/` — Landing personal, donaciones y rifa benéfica (1000 números)
- `tech-and-chic/` — Placeholder
- `frances-sin-estres/` — Placeholder
- `img/` — Recursos gráficos (logotipo VQ)

## Tecnologías

HTML5, Tailwind CSS (CDN), JavaScript ES6+.
